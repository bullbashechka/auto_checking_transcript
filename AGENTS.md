# AGENTS.md

Инструкции для Codex при работе с этим репозиторием.

## Что нельзя трогать

- `.env` содержит секретные ключи (`TELEGRAM_TOKEN`, `OPENAI_API_KEY`). Не читать, не выводить, не редактировать и не коммитить этот файл. Если нужны изменения в переменных окружения, править `.env.example` и просить пользователя обновить `.env` вручную.
- Реальные `xlsx`-табели в корне проекта, например `Сайдашев Кирилл Алексеевич.xlsx`, являются рабочими данными клиента. Их можно читать для тестирования парсера, но нельзя переименовывать или модифицировать на месте. Результаты всегда писать в отдельный файл формата `{stem}_исправленное_{дата}.xlsx`.

## Команды

```bash
pip install -r requirements.txt
python -m src.main
python -m scripts.check_file <path.xlsx>
python -m unittest discover tests
python -m py_compile src/*.py scripts/*.py tests/*.py
```

Назначение:

- `pip install -r requirements.txt` - установить зависимости.
- `python -m src.main` - запустить Telegram-бота в long polling.
- `python -m scripts.check_file <path.xlsx>` - проверить локальный xlsx без Telegram.
- `python -m unittest discover tests` - запустить все юнит-тесты.
- `python -m py_compile src/*.py scripts/*.py tests/*.py` - быстрая проверка синтаксиса.

Линтеров в проекте пока нет. Не добавлять их без отдельной просьбы пользователя.

## Архитектура

Конвейер обработки одного xlsx-табеля:

```text
bot.handle_document  ->  checker.process_file
                              |
              xlsx_processor.parse(path)  -> list[WorkEntry]
                              |
              llm.LLMClient.check(...)  <- конкурентно через Semaphore(LLM_CONCURRENCY)
                              |
              xlsx_processor.write_result(...)  -> новый файл с подсветкой
                              |
                          Report.render()  -> текст в Telegram
```

## Важные детали реализации

### Входной xlsx имеет двухуровневую структуру

Файл не является плоской таблицей. В `src/xlsx_processor.py:parse` колонка `Содержание` ищется по заголовку, затем строки обрабатываются сверху вниз:

- если ячейка `Содержание` пустая, а в колонке A есть значение, это строка-заголовок контрагента;
- если `Содержание` заполнено, это строка работы, к которой добавляется последний найденный контрагент.

Поле `Контрагент` нужно корректно передавать в LLM. Колонка `Содержание` - единственное проверяемое поле.

### Основная логика проверки находится в промте

`src/prompts/system_prompt.txt` задает правила орфографии, эталонный регистр аббревиатур (`1С`, `ИБ`, `ЭСФ` и т.д.), список того, что нельзя трогать, и распознавание незаполненных placeholder-конструкций вроде `(чей ПК)`, `3.0.....`, `(название ИБ)`.

Если нужно изменить поведение модели, чаще всего правится промт, а не Python-код.

LLM возвращает строгий JSON одной из четырех форм:

- пустой результат;
- только исправление;
- только предупреждение;
- исправление и предупреждение.

Маппинг JSON в Python находится в `CheckResult` в `src/llm.py`; поля русские, с алиасами.

### Результат записывается в новый xlsx

- Исправленные ячейки подсвечиваются желтой заливкой (`HIGHLIGHT_FILL`).
- Предупреждения о placeholder'ах подсвечиваются красноватой заливкой (`WARNING_FILL`), при этом текст не изменяется.
- Имя выходного файла фиксировано: `{stem}_исправленное_{YYYY-MM-DD}.xlsx`. Не менять формат без согласования.

### Доступ к боту ограничивается whitelist

`Settings.allowed_user_ids` берется из env. Если whitelist пустой, бот открыт всем в режиме локальной отладки.

Команда `/id` всегда возвращает Telegram ID. Ее используют, чтобы добавить пользователя в whitelist.

### Async и лимит конкурентности

LLM-вызовы выполняются через `asyncio.gather` с `Semaphore(LLM_CONCURRENCY=5)`.

Это компромисс между скоростью и лимитами OpenAI API. Для больших табелей, например больше 100 строк, лимит можно увеличить, но нужно учитывать rate limit.

## Где править

| Задача | Файл |
| --- | --- |
| Добавить новую аббревиатуру в эталонный словарь | `src/prompts/system_prompt.txt` |
| Расширить список placeholder-конструкций | `src/prompts/system_prompt.txt` |
| Поменять формат ответа модели | `src/prompts/system_prompt.txt` и `CheckResult` в `src/llm.py` |
| Поменять модель OpenAI | `.env` (`OPENAI_MODEL`) |
| Изменить структуру входного xlsx или другие колонки | `src/xlsx_processor.py:parse` |
| Поменять имя выходного файла или подсветку | `src/xlsx_processor.py:write_result` |
| Добавить новый Telegram-хендлер | `src/bot.py:build_application` |
