# Установка и запуск с нуля

Пошаговая инструкция: получить API-ключи, подключить их и запустить бота. Рассчитано на ~15-20 минут.

---

## Шаг 1. Получить ключ Google Gemini API

Это самое важное — без этого ключа бот не сможет проверять текст.

1. Открой [https://aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. Залогинься своим Google-аккаунтом (тот же, что для Gmail подойдёт).
3. Нажми **«Create API key»** (или «Создать ключ API»).
4. Если предложит выбрать Google Cloud проект — выбери любой свой существующий или нажми **«Create API key in new project»**.
5. Скопируй полученный ключ. Он выглядит примерно так:
   ```
   AIzaSyB-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
6. **Сохрани его в надёжном месте.** Повторно его показывать не будут — можно только создать новый.

### Бесплатные лимиты Gemini

На момент написания (2026):
- Gemini 2.5 Flash — бесплатный тариф ~10 запросов/мин и ~250 запросов/день.
- Если один табель содержит, скажем, 18 строк — это 18 запросов. То есть бесплатно можно обработать ~13 табелей в день.
- Платный тариф включается автоматически, если привязан биллинг — тогда лимиты в десятки раз выше.

Проверить актуальные лимиты: [https://ai.google.dev/gemini-api/docs/rate-limits](https://ai.google.dev/gemini-api/docs/rate-limits).

## Шаг 2. Создать Telegram-бота

1. В Telegram найди контакт **@BotFather** (официальный, с галочкой).
2. Напиши ему `/newbot`.
3. Придумай имя бота (видимое в чатах) — например `Корректор табелей`.
4. Придумай username бота — обязательно заканчивается на `bot`, например `kirill_timesheet_bot`. Должен быть уникальным.
5. BotFather пришлёт сообщение с токеном вида:
   ```
   7891234567:AAEhB-xxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
6. Скопируй токен. Это и есть `TELEGRAM_TOKEN`.

## Шаг 3. Установить проект локально

В терминале перейти в папку проекта:

```bash
cd /Users/kirillsaidashev/Documents/Projects/actual/auto_checking_transcript
```

Создать виртуальное окружение и поставить зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Должно установиться без ошибок. Если ругается на `python3` — убедись, что установлен Python 3.11+ (`python3 --version`).

---

## Шаг 4. Заполнить `.env`

Скопировать шаблон:

```bash
cp .env.example .env
```

Открыть `.env` в любом редакторе (VS Code, nano, TextEdit) и заполнить:

```dotenv
TELEGRAM_TOKEN=7891234567:AAEhB-xxxxxxxxxxxxxxxxxxxxxxxxxx
GEMINI_API_KEY=AIzaSyB-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# Пока оставить пустым — заполним на шаге 6
ALLOWED_USER_IDS=

GEMINI_MODEL=gemini-2.5-flash
LLM_CONCURRENCY=5
```

> ⚠️ `.env` уже добавлен в `.gitignore` — он не попадёт в git. Но всё равно не пересылай его никому.

## Шаг 5. Проверить, что всё работает (без Telegram)

Можно протестировать всю цепочку парсер → Gemini → исправленный xlsx без запуска бота:

```bash
python -m scripts.check_file "Сайдашев Кирилл Алексеевич.xlsx"
```

(подставь своё имя файла, если используешь другой табель)

Ожидаемый вывод:

```
INFO src.checker: Parsed 18 work entries from Сайдашев Кирилл Алексеевич.xlsx

✓ Обработано строк: 18
✓ Исправлено: 2
⚠ Предупреждения: 0

Исправления:
   • Строка 14: было «Вопро» → стало «Вопрос»
   • Строка 12: был лишний пробел в конце

Файл с правками: /.../Сайдашев Кирилл Алексеевич_исправленное_2026-05-21.xlsx
```

Если вместо этого ругается:
- `RuntimeError: GEMINI_API_KEY is not set` → проверь, что `.env` лежит в корне проекта и в нём заполнен ключ.
- `google.api_core.exceptions.PermissionDenied` или 403 → ключ Gemini неверный или не включён API. Зайди заново на [aistudio.google.com/apikey](https://aistudio.google.com/apikey) и создай новый.
- `429 Too Many Requests` → превышен лимит запросов. Подожди минуту или уменьши `LLM_CONCURRENCY` в `.env` до 2-3.

Открой получившийся xlsx — должны быть подсвечены жёлтым исправленные ячейки.

## Шаг 6. Узнать свой Telegram ID

Самый простой способ — написать стороннему боту [@userinfobot](https://t.me/userinfobot). Он ответит твоим Telegram ID одним сообщением. Скопируй число.

**Альтернатива** — если по каким-то причинам через `@userinfobot` неудобно: можно временно запустить своего бота в открытом режиме. Для этого открой `.env` и поставь:

```dotenv
ALLOW_ANY=true
```

(При пустом `ALLOWED_USER_IDS` без `ALLOW_ANY=true` бот не стартует — это защита от случайного открытия на проде.)

Запусти:

```bash
python -m src.main
```

В Telegram найди своего бота по username, напиши `/start`, потом `/id` — он ответит твоим ID. Останови бота `Ctrl+C`.

## Шаг 7. Закрыть бота whitelist'ом

Открой `.env` и впиши свой ID (и ID коллег через запятую). **Обязательно сбрось `ALLOW_ANY`**, если ставил его на шаге 6:

```dotenv
ALLOWED_USER_IDS=123456789,987654321
ALLOW_ANY=
```

Запусти бота снова:

```bash
python -m src.main
```

В логах:

```
INFO root: Starting bot. Whitelist: [123456789, 987654321]
```

Теперь чужой Telegram ID получит отказ при попытке прислать файл.

## Шаг 8. Боевой тест

В Telegram отправь боту xlsx-табель. Должно произойти:

1. Сообщение «Скачиваю файл…»
2. Через пару секунд: «Анализирую содержание, это может занять минуту…»
3. Через 5-30 секунд (зависит от количества строк) — отчёт с исправлениями.
4. Следом — исправленный xlsx с именем `{твой_файл}_исправленное_2026-05-21.xlsx`.

Если что-то пошло не так — посмотри логи в терминале, где запущен бот.

## Добавить коллегу в whitelist

1. Попроси коллегу написать [@userinfobot](https://t.me/userinfobot) — это сторонний бот, который сразу покажет его Telegram ID.
2. Получив ID коллеги, открой `.env`, добавь его в `ALLOWED_USER_IDS` через запятую.
3. Перезапусти бота (`Ctrl+C` → `python -m src.main`).

(Команда `/id` у твоего бота тоже работает, но только для пользователей уже в whitelist — поэтому новому коллеге она не поможет.)

## Поменять модель Gemini

В `.env` поменяй `GEMINI_MODEL`. Варианты:
- `gemini-2.5-flash` — быстрая, дешёвая, рекомендую по умолчанию.
- `gemini-2.5-pro` — точнее, но медленнее и платная.
- `gemini-2.0-flash-001` — более старая, если Flash 2.5 будет недоступна.

Список актуальных моделей: [https://ai.google.dev/gemini-api/docs/models](https://ai.google.dev/gemini-api/docs/models).

---

## Что делать, если бот завис

В терминале нажми `Ctrl+C` — бот корректно остановится. Запусти снова: `python -m src.main`.

Если завис в активном диалоге (например, на скачивании файла) и `Ctrl+C` не помогает — нажми ещё раз или закрой терминал. Telegram-обновления никуда не денутся, бот получит их при следующем старте.
